# Unique Domains Datasets

Public extracts of one-word domain names from [Unique Domains](https://unique.domains/domains?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=top_open_search): which are free to register, what they cost to hold and what names of each ending sell for. The domain datasets below are rebuilt every night, ship as CSV and JSON and are free under CC BY 4.0.

Each repository links the page it extracts; every ending Unique Domains tracks is on [unique.domains/tld](https://unique.domains/tld?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=related_hub).
