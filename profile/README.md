# Unique.domains Datasets

Domain data you can load in one line. Each repository below is a public extract of the one-word domain names [Unique.domains](https://unique.domains/domains?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=top_open_search) reads every day: which are free to register, what they cost in the first year and what they renew at. Rebuilt every night, CSV and JSON, free under CC BY 4.0.

Need more than a file? The same rows answer live with no key at `https://api.unique.domains/v1/domains`, from Node (`npm install @uniquedomains/sdk`), Python (`pip install uniquedomains`) or an AI assistant (`https://mcp.unique.domains/mcp`). Every ending Unique.domains tracks is on [unique.domains/tld](https://unique.domains/tld?utm_source=github&utm_medium=referral&utm_campaign=org_profile&utm_content=related_hub).
